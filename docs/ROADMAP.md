# Roadmap

This is a dependency-ordered roadmap, not a promise of dates.

## Foundation
- [ ] Repository governance and AI collaboration workflow.
- [ ] ADR process and language adoption policy.
- [ ] Threat model and data classification.
- [ ] Domain glossary and capability model.
- [ ] Research questions and evidence log.

## Discovery
- [ ] Compare candidate global data providers and legal terms.
- [ ] Define normalized merchant/location schema.
- [ ] Design provenance and freshness model.
- [ ] Benchmark geographic and text search approaches.
- [ ] Build ingestion prototype only after source approval.

## Catalogue
- [ ] Define merchant-authoritative menu contract.
- [ ] Define item/modifier/version model.
- [ ] Design checkout-time price/availability validation.

## Native ordering
- [ ] Select one pilot merchant integration.
- [ ] Define merchant acceptance path.
- [ ] Evaluate payment/settlement arrangements for pilot market.
- [ ] Implement sandbox transaction and reconciliation flow.

## Fulfilment
- [ ] Compare merchant delivery and third-party provider capabilities.
- [ ] Define serviceability and delivery quote contract.
- [ ] Implement one sandbox adapter.
- [ ] Test real pilot with an approved merchant and fulfilment route.

## Customer applications
- [ ] Premium responsive web/PWA.
- [ ] Guest-first session and order access.
- [ ] Destination independent from device location.
- [ ] Optional account.
- [ ] Flutter/Dart mobile client when justified.

## Research and algorithms
- [ ] Maintain reproducible benchmark datasets and baselines.
- [ ] Evaluate restaurant deduplication/entity resolution.
- [ ] Evaluate source freshness and confidence scoring.
- [ ] Evaluate geographic serviceability/indexing.
- [ ] Evaluate ETA uncertainty only with legitimate, consented/authorized data.
- [ ] Promote an algorithm to production only after evidence and review.
